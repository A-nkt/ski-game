# SNOWLINE 3D — Alpine Rush

ブラウザで遊べる、Three.js製の3Dスキーゲームです。

## 遊び方

- `←` `→` または `A` `D`: ターン
- `↓` または `S`: タック（加速する代わりに操舵応答が低下）
- `Space` または `↑`: ジャンプ
- スマートフォン: 画面下のボタン
- 右上の `♪`: サウンドのオン／オフ

滑走中の風、ターン、ジャンプ、着地、コイン、衝突の効果音と、スタート・ゲームオーバー・記録更新時のボイスが鳴ります。ブラウザの仕様上、最初に `RIDE NOW` を押したあとから音声が有効になります。

木や岩のすぐ横を地上で通過すると「ニアミス」になり、専用SEとともに距離ボーナス `+25m` を獲得できます。

## ビジュアルとカメラ

- 写真調のアルプス背景、実写調スキーヤー、雪をかぶった針葉樹をローカル素材として同梱
- 雪面には風紋、圧雪の色むら、微細な氷粒、パウダードリフトを組み合わせた動的な凹凸を使用
- 滑走したラインには左右2本のスキー溝が残り、カービング弧を視覚化
- 雪しぶきは硬い粒雪と柔らかい粉雪ミストの二層構成で、カービング・パンプ・着地に反応
- ゲーム酔いを抑えるため、カメラは固定距離・水平維持
- FOVのみ速度に応じて66〜75°へ緩やかに変化
- ランダムなカメラ揺れ、ターン時の画面ロール、ズーム脈動は不使用

左右操作は平行移動ではなく、エッジ角→スキーの向き→旋回弧→横速度の順に変化するカービングモデルです。入力を離した直後も慣性が残り、身体の倒し込みは旋回加速度から計算されます。

スキーヤーは速度に応じたタック姿勢、カービング荷重に応じた膝・腰の屈曲、切り返し時の伸び、着地時の深い吸収動作を行います。ターン時は内脚を深く曲げ、外脚を長く保ち、膝と腰をターン内側へ入れながら上体を起こす左右非対称のアンギュレーションを使用します。切り返しのエッジ応答と最大旋回幅は、カメラを揺らさず身体と滑走ライン側でダイナミックさが出るよう調整しています。

画像を個別配信・キャッシュするため、ローカルHTTPサーバー経由で起動します。

```sh
npm run dev
```

その後、`http://localhost:8000` を開いてください。`file://` での直開きは、ブラウザのWebGL画像セキュリティ制約により非対応です。

`npm run build` では約500KBのJavaScriptと、ハッシュ付きの画像ファイルを個別に生成します。ゲーム開始ボタンは3枚の画像ロードが完了するまで無効になります。

## G0 爽快感コア

- 深いエッジを0.4秒以上保ってニュートラルへ切り返すと、カービングパンプで加速
- タック中は目標速度が18%上がり、姿勢が深くなる代わりに操舵応答が半減
- ニアミスと真っ直ぐな着地でもブーストを獲得。エッジを立てた着地は15%減速
- 速度40m/s以上で周辺流線、45m/s以上で第2層のハウリング風音が出現
- 着地、ニアミス、クラッシュ時は対応端末で短い触覚フィードバック
- 自動6ラン計測では、漫然プレイ平均33.87m/sに対し上級操作平均42.10m/s（+24.3%）

## G1 地形とライン

- 低頻度のローラー地形を追加し、38m/s以上で尾根の下り側へ抜けると自然にジャンプ
- クレストジャンプは既存のBIG AIR、HUGE AIR、クリーン着地判定と連動
- 30〜60m単位で散布、スラローム、レーシングラインのパターンを抽選
- スラロームでは木のゲートとコインが左右交互に並び、切り返しとパンプのリズムを誘導
- レーシングラインではサイン軌道のコイン列が速い旋回ラインを可視化
- 4ゾーンごとに各パターンの出現率が変化

## G2 スタンブル

- 障害物の中心は従来どおりクラッシュし、0.25mのかすり帯ではランが継続
- スタンブル時は速度55%・ブースト0になり、深い屈伸とつんのめり、専用SEを再生
- スタンブル帯の外側だけがニアミスになる排他的な3層判定
- 高速時の判定抜けを防ぐため、障害物面のフレーム間通過も衝突判定

## P0エンゲージメント

- ニアミスは4秒以内に連鎖し、最大×5・+125mまで上昇
- 12%でゴールドコインが出現し、5枚分と+60mを獲得
- コイン10枚で8秒間のフィーバーが発動し、蛇行する40枚のコインラインが出現
- フィーバー中はコイン価値2倍・速度8%増加。カメラ設定は変化しません
- ベスト記録の70%から残距離をライブ表示し、更新瞬間と100m以内の惜敗を専用演出
- ゲームオーバー後は `Enter` または `R` でリスタート

## P1ラン構成

- 0.8秒以上のジャンプで `BIG AIR +15m`、1.4秒以上で `HUGE AIR +40m`
- 30%のジャンプ台には、空中で取得できる6枚のコインアーチが出現
- 400mごとにNORMAL、密林、ロックガーデン、コイン回廊をローテーション
- 密林はニアミス、ロックガーデンはジャンプ、コイン回廊は回収と休息に特化
- 500mごとにチャイムと距離パルス、1000mごとに距離ボイス

## P2継続プレイ

- 累計コイン数と滑走回数をブラウザに保存し、スタート画面に表示
- 累計50コインでACID、200コインでGOLDのスノースプレーを解放
- 1000m到達、ニアミス×5、1ラン30コインの3実績を永続保存
- 衝突時はカメラを傾けず、0.9秒のスローモーションと身体の転倒動作を挟んで結果を表示
